# FreshMart 🛒

FreshMart is a modern, responsive online supermarket and grocery delivery web application.

## 🌿 Features

- **Product Catalog & Categorization**: Browse products across categories like Fruits & Veggies, Dairy & Eggs, Bakery, Meat & Seafood, Beverages, and Snacks.
- **Search & Filtering**: Live search bar with instant results and category filters.
- **Shopping Cart**: Add to cart, quantity controls, cart badge counter, and checkout calculations.
- **Dark / Light Mode**: Interactive theme toggle with persistent preferences.
- **Responsive Design**: Mobile-friendly navigation with hamburger menu and adaptable layouts.
- **Pages**:
  - `index.html`: Home page featuring hero banner, daily deals, categories, and reviews.
  - `products.html`: Product listing with filters and sorting.
  - `cart.html`: Interactive shopping cart and order summary.
  - `about.html`: About FreshMart, story, mission, and core values.
  - `contact.html`: Contact form, store locations, and FAQs.

## 🚀 Tech Stack

- **HTML5** & **CSS3** (Custom variables, responsive grid & flexbox layouts, animations)
- **JavaScript (Vanilla)**
- **Font Awesome Icons** & **Google Fonts** (Fraunces & DM Sans)

## 💻 Getting Started

Simply open `index.html` in any web browser, or serve it using any local static server:

```bash
# Using VS Code Live Server or Python
python -m http.server 8000
```
